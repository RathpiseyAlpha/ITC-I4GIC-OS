A pipe joins two commands

  • The pipe | connects the stdout of one command to the stdin of the next.
  • The commands run at the same time. Data flows through as it is produced.
  • Only stdout goes through the pipe. stderr still goes to the terminal.
  • The exit status of a pipeline is, by default, the status of the last command.

student@server: ~/oslab-work/lab4

$ printf 'ok,3\nfail,2\n'

ok,3

fail,2

$ printf 'ok,3\nfail,2\n' | grep '^ok,'

ok,3

$ printf 'ok,3\nfail,2\n' | grep '^ok,' | cut -d, -f2

3

Read it stage by stage: all rows, then only the ok rows, then only field 2 of those rows.
