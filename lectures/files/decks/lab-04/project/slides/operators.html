The redirection operators

OperatorMeaningExample
>Send stdout to a file, replacing itls > files.txt
>>Append stdout to a fileecho done >> log.txt
2>Send stderr to a filels /fake 2> errors.txt
2>&1Make stderr go where stdout goes nowcmd > all.txt 2>&1
&>Bash shorthand: stdout and stderr into one filecmd &> all.txt
<Read stdin from a filesort < unsorted.txt
/dev/nullThrow the output awaycmd > /dev/null 2>&1

A single > replaces the file. Use >> to add to it. In a pipeline, |& sends both streams to the next command.
