Small filters, one job each

CommandWhat it doesExample
grepKeeps the lines that match a patterngrep '^ok,' events.csv
cutTakes fields from each linecut -d, -f2
awkFields, conditions and arithmeticawk '{ total += $1 } END { print total+0 }'
sort, uniq -cSort lines, then count equal neighbourssort data | uniq -c
wc -lCounts lineswc -l file.txt
head, tailThe first or last lineshead -n 1
teeSaves a copy and passes the data onls | tee files.txt | wc -l

uniq compares neighbours only, so sort first. tee lets you look inside a pipeline.
