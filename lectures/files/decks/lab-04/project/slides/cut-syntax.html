cut syntax and field lists

SyntaxWhat it doesExample
-d DELIMSet the input field separator. The default is a tab.cut -d ',' -f 2 events.csv
-f LISTSelect field numbers starting at 1cut -d, -f2 events.csv
-f1,3Select fields 1 and 3cut -d, -f1,3 people.txt
-f2-3Select fields 2 through 3cut -d, -f2-3 people.txt
-f2-Select from field 2 to the endcut -d, -f2- people.txt
-sSkip lines with no delimiter in field modecut -s -d, -f2 people.txt
-c LISTSelect character positions in ASCII textcut -c1-3 people.txt

Syntax: cut -d DELIM -f LIST [FILE ...] or cut -c LIST [FILE ...]. Omit the file to read stdin. Use field mode for simple delimited text.
