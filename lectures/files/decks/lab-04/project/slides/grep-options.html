Common grep options

OptionWhat it doesExample
-iIgnore casegrep -i '^READY,' events.csv
-nShow the line number with each matchgrep -n '^ready,' events.csv
-vSelect lines that do not matchgrep -v '^status,' events.csv
-cPrint the number of selected lines per filegrep -c '^ready,' events.csv
-oPrint only the matched parts, one per linegrep -o '[[:digit:]]$' events.csv
-xRequire a match across the whole linegrep -x 'ready,4' events.csv
-EUse extended regular expressionsgrep -E '^(ready|done),' events.csv
-FTreat the pattern as literal textgrep -F 'ready-late,' events.csv
