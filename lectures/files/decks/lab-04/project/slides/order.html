The order of redirections matters

stderr follows stdout to the file

student@server: ~/oslab-work/lab4

$ bash -c 'echo normal; echo problem >&2' > both.txt 2>&1

$ cat both.txt

normal

problem

First stdout goes to the file. Then 2>&1 points stderr at that same place.

stderr stays on the screen

student@server: ~/oslab-work/lab4

$ bash -c 'echo normal; echo problem >&2' 2>&1 > only-out.txt

problem

$ cat only-out.txt

normal

Here stderr is pointed at stdout while stdout is still the screen. Only then does stdout move to the file.

Read redirections from left to right.
