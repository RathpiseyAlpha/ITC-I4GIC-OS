example values: use your own words

$ printf 'ready,3\ndone,2\n' | grep '^ready,' | cut -d, -f2

In the instruction these lines say STATUS and OTHER. Type your own words. The example uses ready and done.

Run each line and read the result before you add the next stage. cut -d, -f2 cuts each line at the commas and keeps the second field.
