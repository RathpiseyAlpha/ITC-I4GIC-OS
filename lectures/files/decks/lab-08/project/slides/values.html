Your values, kept in variables

1. The command prints your values

example: your values will be different

$ oslab values lab8

Your personal values for lab8 (your-account):

  stock    = 9

  buyer_a  = 7

  buyer_b  = 8

2. Type them into shell variables

type your own values

$ stock=9

$ buyer_a=7

$ buyer_b=8

Write name=value with no spaces around =. In a new terminal, run cd into the lab folder and set them again.
