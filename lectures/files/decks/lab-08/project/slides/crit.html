A critical section touches shared data

  • Shared data is something more than one program can change: here, a stock file.
  • A critical section is the part of a program that reads and then changes that shared data.
  • While one program is inside, no other program may be inside. This is mutual exclusion.
  • The rule must cover the whole sequence: read, decide, write.

FOR THE WHOLE COURSE

Why learn it here?

Every shared file, database and counter has this problem. The same idea returns in the lectures on semaphores and monitors.
