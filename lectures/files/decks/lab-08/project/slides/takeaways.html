Critical section

The read, the decision and the write belong together. Protect all of them.

02

A race is about timing

It may pass many times and then fail. A delay makes it visible, it does not cause it.

03

flock

An advisory lock on a shared file. Every program must ask, and all must use the same file.

04

Test the fix

Use the same run as before, and check the rule: sold plus left equals the start.
