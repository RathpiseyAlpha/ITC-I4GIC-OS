Setup: start the lab

student@server: ~

$ whoami

$ command -v oslab

$ oslab doctor

$ export OSLAB_WORKSPACE="${OSLAB_WORKSPACE:-$HOME/oslab-work}"

$ oslab start lab6

$ cd "$OSLAB_WORKSPACE/lab6"

$ pwd

$ mkdir -p evidence

$ find . -maxdepth 3 -type f

  • whoami shows your account. command -v oslab and oslab doctor check the helper.
  • If the helper is missing, follow the local setup guide in the course repository.
  • oslab start lab6 makes the lab folder. It keeps your work if you start again, and it does not change your current folder, so cd into it yourself.
  • If you are resuming, look at the existing files before you run a command that writes to them.
