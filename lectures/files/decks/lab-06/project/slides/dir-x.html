On a directory, x means search

READ

r on a directory

You may list the names inside it, with ls.

SEARCH

x on a directory

You may pass through it to reach an entry whose name you already know. Without x you cannot open anything below it.

TOGETHER

Both are needed to browse

To list names and open files you need r and x. A directory with only r shows names but opens nothing.

Do not try to run a data file to test read permission. For a directory, x is not about running a program.
