Two ways to run it

student@server: ~/oslab-work/lab7

$ bash show_args.sh 'one file.txt' '-dash.txt'

argument count=2

<one file.txt>

<-dash.txt>

 

$ chmod u+x show_args.sh

$ ./show_args.sh 'one file.txt' '-dash.txt'

bash script runs the file with Bash, whether or not it is executable.

./script runs it directly. That needs the execute bit and the shebang. ./ names the file in the current folder, which is not on PATH.

chmod u+x gives the owner the execute bit.

If a direct run says Permission denied, the file may lack the execute bit, or the folder may be mounted noexec. bash script is the allowed fallback.
