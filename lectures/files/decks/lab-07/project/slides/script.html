A script is a saved list of commands

show_args.sh

#!/usr/bin/env bash

printf 'argument count=%s\n' "$#"

for argument in "$@"; do

    printf '<%s>\n' "$argument"

done

The first line, the shebang, names the interpreter that should run the file.

$# is the number of arguments. $@ is the list of arguments. for repeats the body once for each of them.

printf with angle brackets shows exactly where each argument starts and ends.
