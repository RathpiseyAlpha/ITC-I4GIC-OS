Step 1: write the argument viewer

student@server: ~/oslab-work/lab7

$ cat > show_args.sh <<'SH'

$ #!/usr/bin/env bash

$ printf 'argument count=%s\n' "$#"

$ for argument in "$@"; do

$     printf '<%s>\n' "$argument"

$ done

$ SH

$ bash show_args.sh 'one file.txt' '-dash.txt'

cat > file <<'SH' writes everything up to the line SH into the file. This is a here-document.

The quotes around SH stop your own shell from expanding $# and $@ while you type. They are left for the script.

Expected: a count of 2, then two arguments in angle brackets.
