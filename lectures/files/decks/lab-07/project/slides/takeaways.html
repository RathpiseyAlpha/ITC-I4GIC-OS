Key takeaways

01

A script is saved commands

A shebang names the interpreter, and chmod u+x lets you run the file directly.

02

Quote what you expand

"$@" keeps each argument whole. Unquoted, a space splits it into two words.

03

-- ends the options

Use it before file names, so a leading dash cannot be read as an option.

04

The status is the message

Exit non-zero when any input failed, even if you carried on with the rest.
