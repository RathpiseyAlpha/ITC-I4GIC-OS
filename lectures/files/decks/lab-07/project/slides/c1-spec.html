What count_words.sh must do

Requirements

  • No arguments: print a usage message on stderr and end with a status other than 0.
  • For each regular file: print one line with the file's name and its word count. The wording of the label is yours.
  • For a missing or non-regular file: a message on stderr, continue with the next arguments, and a final status other than 0.
  • Keep each argument in one piece, and pass file names to wc after --. Do not use eval.

You write it

Build it from the argument loop of the guided part. Different, reasonable output labels are accepted.
