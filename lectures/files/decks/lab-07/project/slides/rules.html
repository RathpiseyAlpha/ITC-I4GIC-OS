How you work

Core, Plus, Challenge

Core is for everyone. Plus and Challenge are for students who finish early. Full marks need only Core and the checkpoint.

AI tools

Allowed in Core, Plus and Challenge, so test every suggestion with your own file names. Not allowed in the prediction and the checkpoint.

You write the script

In Core 1 you receive an empty skeleton. You write the script, and you decide how to keep the exit status.

Do not use eval, and do not run scripts you did not write. A wrong prediction costs nothing.
