Your own commands on PATH

student@server: ~/oslab-work/lab7

$ mkdir -p ~/bin

$ cp count_words.sh ~/bin/count_words

$ export PATH="$HOME/bin:$PATH"

$ command -v count_words

/home/student/bin/count_words

PATH is the list of folders the shell searches for a command name. Add your own folder in front, and the script runs without ./.

export PATH=... lasts for this shell only. Put it in ~/.bashrc to keep it, and read that file again with source ~/.bashrc.
