Every command ends with an exit status

StatusMeaning
0Success
1 and aboveSome kind of failure
2By habit, a wrong use of the command

student@server: ~/oslab-work/lab7

$ test -f input/one\ file.txt; echo $?

0

$ test -f missing.txt; echo $?

1

$? holds the status of the last command. A script ends with the status you give to exit, or with the status of its last command.
