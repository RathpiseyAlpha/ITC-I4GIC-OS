Login messages, outbox and the mailbox idea

LOGIN

A message when you log in

A line in ~/.bash_profile or ~/.bashrc can print a notice. Preview it with a plain command before you rely on it.

OUTBOX

An owned outbox

A folder you own where a script leaves messages. Only you write to it, so permissions stay simple.

MAILBOX

A cross-user mailbox

Needs a narrow shared folder the instructor prepared, with write permission only for the people who need it. Never open your own home.

A program that runs with its owner's rights (setuid) is a concept for a prepared virtual machine. It is not part of this lab.
