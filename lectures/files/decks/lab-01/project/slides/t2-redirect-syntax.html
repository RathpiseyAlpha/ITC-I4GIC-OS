The syntax of > and >>

You typeWhat it meansIf the file is newIf the file exists
COMMAND > FILESend the output into FILEFILE is createdIts old content is replaced
COMMAND >> FILEAdd the output to the end of FILEFILE is createdIts old content stays, and the new output comes after it

One arrow replaces

Think of > as: start this file again.

Two arrows add

Think of >> as: write on the next line.

The command does not change

Only where its output goes changes. COMMAND can be any command.
