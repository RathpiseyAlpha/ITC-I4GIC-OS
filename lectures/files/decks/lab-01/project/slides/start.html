Start the lab

student@server: ~

$ oslab doctor             # before class

$ oslab prelab lab1        # before class

$ oslab start lab1

$ cd ~/oslab-work/lab1

$ oslab values lab1

$ oslab check lab1

  • oslab start lab1 makes your lab folder.
  • cd takes you into it. You work there for all of Part A.
  • oslab values lab1 prints your personal values. The next slide explains them.
  • oslab check lab1 prints one line for each part of the lab: TRY means not done yet, PASS means done.

At the start every line of oslab check lab1 says TRY, because you have not done anything yet.
