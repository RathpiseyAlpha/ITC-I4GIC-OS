Task 3: what each command does

CommandWhat it does
sudo apt-get updateRefreshes the list of available software. Installs nothing.
sudo apt-get install mcDownloads and installs the package.
sudo apt-get remove mcUninstalls the program. Keeps its settings in /etc.
sudo apt-get purge mcUninstalls the program and deletes its settings.

mc is Midnight Commander. Its settings live in the folder /etc/mc.
