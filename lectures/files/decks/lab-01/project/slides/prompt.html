The prompt

When a terminal starts, the shell shows a prompt. Its structure varies between distributions, but it typically tells you about the user and the system.

User name

terminal

sysadmin@localhost:~$

System name

terminal

sysadmin@localhost:~$

Current directory

terminal

sysadmin@localhost:~$

The $ at the end means you are a normal user, and the shell is waiting for your command.
