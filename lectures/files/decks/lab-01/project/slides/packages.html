Package management

01

Packages

A distribution is normally split into packages. Each package holds one application or service.

02

What a package holds

The software, and metadata: its full name, a description of its purpose, a version number, a checksum, and the list of dependencies it needs to run.

03

The package manager

A collection of tools that automates installing, upgrading, configuring and removing programs, in a consistent way.

A dependency is another package that this one needs.
