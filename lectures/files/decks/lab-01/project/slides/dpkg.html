DPKG

DPKG is the package manager of Debian-based systems.

It can install, remove and build packages. Unlike other package managers, it cannot download and install packages or their dependencies by itself.

$ dpkg -l                 # list all installed packages

$ dpkg -l | grep xxx      # check if xxx is installed

$ sudo dpkg -i xxx.deb    # install xxx.deb

$ sudo dpkg -r xxx        # uninstall xxx
