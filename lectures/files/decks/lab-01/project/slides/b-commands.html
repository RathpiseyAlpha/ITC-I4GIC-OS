Task 3: the three steps

you@your-ubuntu: ~/os-gic-YOUR_ID/os-lab-YOUR_ID/lab1

$ sudo apt-get update

$ sudo apt-get install mc -y

$ which mc > task3_apt.txt

$ ls -ld /etc/mc >> task3_apt.txt

$ sudo apt-get remove mc -y

$ ls -ld /etc/mc >> task3_apt.txt

$ sudo apt-get purge mc -y

$ ls -ld /etc/mc >> task3_apt.txt 2>&1

$ cat task3_apt.txt

2>&1 also saves the error message when the folder is gone.

Then take a screenshot of the last ls -ld /etc/mc and keep it as task3.png.
