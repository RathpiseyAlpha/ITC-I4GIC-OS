Make, write and record

student@server: ~/oslab-work/lab1

$ mkdir task2_files

$ cd task2_files

$ pwd > ../task2_file_commands.txt

$ ls >> ../task2_file_commands.txt

$ touch FILE1.txt FILE2.txt

$ ls >> ../task2_file_commands.txt

$ echo "This is file FILE1" > FILE1.txt

$ echo "This is file FILE2" > FILE2.txt

$ cat FILE1.txt FILE2.txt >> ../task2_file_commands.txt

Replace FILE1 and FILE2, shown in orange, with your own file1 and file2.

Every result goes into the record file. The first line uses >, the rest use >>.
