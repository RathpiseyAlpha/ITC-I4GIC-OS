A Linux distribution, or distro

An operating system made from a software collection, based on the Linux kernel and, often, a package management system.

A typical distribution comprises

  • A Linux kernel
  • GNU tools
  • Others: libraries, additional software, documentation, a window system, a window manager and a desktop environment
