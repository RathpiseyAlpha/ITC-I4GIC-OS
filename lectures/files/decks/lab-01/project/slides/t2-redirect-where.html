Where does the output of a command go?

Normally: to the screen

ls

a command

its output

the standard output

the screen

you read it, then it is gone

With > or >>: into a file

ls > list.txt

the same command, redirected

its output

the standard output

list.txt

it is saved, and the screen shows nothing

This is called output redirection. You use it in every task to keep a record of your results.
