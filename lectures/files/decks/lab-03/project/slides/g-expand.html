Step 2: how the shell expands a pattern

student@server: ~/oslab-work/lab3

$ printf '<%s>\n' practice/*.txt

$ printf '<%s>\n' practice/report?.txt

$ printf '<%s>\n' 'practice/*.txt'

The first two commands name the two text files. The quotes around the whole pattern in the third leave a literal *.

Brace expansion such as {1,2} generates words. It is not a test against file names.
