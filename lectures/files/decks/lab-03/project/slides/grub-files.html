GRUB files and key settings

FilePurposeEdit?
/boot/grub/grub.cfgThe generated menuNever
/etc/default/grubTimeout, kernel parametersYes
/etc/grub.d/Scripts, custom entriesYes
/boot/vmlinuz-*The compressed kernelNo
SettingMeaningExample
GRUB_DEFAULTEntry to boot0
GRUB_TIMEOUTSeconds at the menu10
GRUB_CMDLINE_LINUX_DEFAULTKernel parametersquiet splash
GRUB_BACKGROUNDA menu background image/boot/grub/bg.png

After you edit /etc/default/grub, run sudo update-grub. Custom entries go in /etc/grub.d/40_custom. Do this only in a disposable virtual machine, never on the shared server.
