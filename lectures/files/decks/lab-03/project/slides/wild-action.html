student@server: ~/oslab-work/lab3

$ ls *.txt

$ ls report0[1-3].txt

$ ls log_[!j]*.log

$ touch memo_{mon,tue,wed}.txt

$ cp *.csv archive/

$ ls *.tmp

$ rm *.tmp

The first three list files. touch with braces creates three files in one command.

cp copies every .csv file into archive/.

CAUTION

Preview before you delete

Run ls *.tmp first. If the list is what you expect, then run rm *.tmp.
