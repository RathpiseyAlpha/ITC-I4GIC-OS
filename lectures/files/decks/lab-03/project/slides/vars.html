Type your values into shell variables

example values: use your own

$ name=maple

$ tag=old

$ v1=417

$ v2=463

  • A variable is a name that holds a value. Write name=value with no spaces around the =.
  • After this, the shell replaces "$name" with your report name, "$tag" with your word, and so on.
  • Always write the variable in double quotes.
  • If you open a new terminal, run cd and set the variables again.

Everything in the lab uses these four variables. Do not copy the example values. Use the ones oslab values lab3 printed.
