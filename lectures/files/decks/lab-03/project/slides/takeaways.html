Key takeaways

01

Wildcards

The shell expands a pattern into names before the command runs. Quote a pattern to keep it literal.

02

Name and inode

A file name is an entry that points to an inode. Hard links are more names for one inode.

03

Symbolic links

A symbolic link stores a path. A relative target is read from the link's folder.

04

Evidence

Rename, look, repair, replace. Each step has a record you can check.
