Capacity, length and allocation

SizeToolAnswers
Capacity and free spacedf -hTHow big is the whole filesystem, and how much is free?
Apparent lengthls -l, stat %sHow many bytes does the file claim to have?
Allocated spacedu -h, stat %b x %BHow many disk blocks does the file really occupy?

The three can differ. df covers a whole mounted filesystem, not one file. A sparse file can be long and small at the same time.
