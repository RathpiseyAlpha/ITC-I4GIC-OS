Key takeaways

01

Three sizes

Capacity is for a filesystem, length is for a file, and allocation is the space really used.

02

Sparse files

Holes read as zeros and use no blocks, so length and allocation can differ a lot.

03

Only your own regular files

Never aim a format command at a device. Check the path first.

04

Say what you measured

A header you read is evidence. A supplied trace is only an illustration.
