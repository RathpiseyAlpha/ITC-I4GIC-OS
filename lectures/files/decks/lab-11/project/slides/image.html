A disk image is a regular file

IMAGE

A file that acts as a disk

A disk image is an ordinary file whose bytes are laid out like a disk. A tool can format it like a disk.

SAFETY

Check before you format

Make sure it is a regular file, not a link, and that it is inside your own workspace. Never point a tool at a /dev/ device.

FORMAT

Formatting adds metadata

mkfs writes structures that describe the filesystem. The length stays the same, but some blocks are now allocated.
