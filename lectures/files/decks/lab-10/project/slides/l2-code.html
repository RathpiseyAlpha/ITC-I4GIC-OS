Step 1: the starting script

backup.sh

#!/usr/bin/env bash

set -euo pipefail

work=$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd -P)

mkdir -p "$work/backups"

stamp=$(date -u +%Y%m%dT%H%M%S%N)

final="$work/backups/backup-$stamp-$$.tar.gz"

pending=$(mktemp "$work/backups/.pending-XXXXXX")

trap 'rm -f -- "$pending"' EXIT

tar -czf "$pending" -C "$work" project

tar -tzf "$pending" >/dev/null

mv -- "$pending" "$final"

# TODO: retain only the newest three completed backup-*.tar.gz files.

printf 'created %s\n' "$final"

Save it as backup.sh and run it with bash backup.sh. set -euo pipefail stops the script on an error, on an unset variable, or when a command in a pipeline fails.

work is the folder that holds the script (BASH_SOURCE[0] is its path, dirname drops the file name, pwd -P prints the real folder), so it works from any folder.

The archive is built under a temporary name and moved into place only when complete. trap removes the temporary file if something fails. The orange TODO is your work: retention.
