A backup is proven by restoring it

student@server: ~/oslab-work/lab10

$ mkdir -p restore-demo

$ tar -xzf demo.tar.gz -C restore-demo

$ cmp -- project/report.txt restore-demo/project/report.txt

$ cmp -- project/config.ini restore-demo/project/config.ini

Extract into a new, empty folder you own. Then compare each file with the original.

cmp prints nothing and returns 0 when the bytes are equal. Creating an archive without error does not show it can be restored.

CAREFUL

Only your own archives

Extract only archives you made. Never extract an unknown archive on the server.
