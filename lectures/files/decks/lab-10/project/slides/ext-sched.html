Schedule the repaired backup

student@server: ~/oslab-work/lab10

$ crontab -l

$ */5 * * * * /bin/bash /home/student/oslab-work/lab10/backup.sh >> /home/student/oslab-work/lab10/cron.log 2>&1

Install it only after backup.sh works under the bare environment. Use absolute paths for the shell, the script and the log.

2>&1 sends error messages to the log too, so you can see why a run failed. Remove the entry when you have seen it run.
