Step 1: run it under a bare environment

student@server: ~/oslab-work/lab10

$ cd "$HOME"

$ env -i HOME="$HOME" PATH=/usr/bin:/bin /bin/bash "$OSLAB_WORKSPACE/lab10/backup.sh"

$ cd "$OSLAB_WORKSPACE/lab10"

env -i starts the command with an empty environment, and then only HOME and PATH are set. This is close to what cron gives a job.

This tests path and environment assumptions. It is not real cron delivery.

The script's own-folder line should still find the project.
