tar joins files, gzip shrinks them

student@server: ~/oslab-work/lab10

$ tar -cf demo.tar -C "$PWD" project

$ tar -tf demo.tar

$ tar -czf demo.tar.gz -C "$PWD" project

$ tar -tzf demo.tar.gz

tar combines files and folders into one archive. gzip compresses the bytes of that archive.

-c creates, -t lists, -x extracts, -f names the archive file, and -z adds gzip.

-C "$PWD" project stores the folder as project/..., so the paths inside do not depend on where you stood.

A very small archive can be larger when compressed, so no compression ratio is promised.
