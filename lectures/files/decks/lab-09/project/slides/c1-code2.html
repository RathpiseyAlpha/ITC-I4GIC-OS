Step 1: the first lock and the barrier, part 2

vault/worker.sh (2 of 3)

exec 8>"$vault/$first.lock"

flock -x -w 2 8 || { echo "$role first lock timeout"; exit 3; }

printf '%s holds %s\n' "$role" "$first"

sleep "${HOLD:-0}"   # teaching delay; keep this line

if [[ "$mode" = opposite ]]; then

    touch "$vault/coord/$role.ready"

    other=B

    [[ "$role" = B ]] && other=A

    for step in {1..30}; do

        [[ -f "$vault/coord/$other.ready" ]] && break

        sleep 0.1

    done

    [[ -f "$vault/coord/$other.ready" ]] || { echo 'barrier timeout'; exit 4; }

fi

Each worker takes its first lock on descriptor 8, waiting two seconds at most. The sleep line is a teaching delay: keep it.

The barrier makes both workers announce their first lock before either asks for the second. It is used only in opposite mode.
