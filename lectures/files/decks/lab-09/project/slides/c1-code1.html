vault/worker.sh (1 of 3)

#!/usr/bin/env bash

set -euo pipefail

# (the check of the two arguments is left out here)

role=$1

mode=$2

vault=$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd -P)

res1=haze

res2=ember

mkdir -p "$vault/coord"

# Worker A takes haze first and ember second. Worker B the other way.

first=$res1; second=$res2

# TODO: in ordered mode, every worker must use one global order.

if [[ "$role" = B ]]; then tmp=$first; first=$second; second=$tmp; fi

Read it with cat -n vault/worker.sh. The values are an example: yours hold your own names, and your own first lock for A.

set -euo pipefail stops on an error, on an unset variable, and when any command in a pipeline fails.

The vault= line finds the script's own folder. B reverses the order by default: the TODO is yours to fix in Core 2.
