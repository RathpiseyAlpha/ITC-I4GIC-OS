Step 1: the barrier, part 2

vault/worker.sh (2 of 3)

if [[ "$mode" = opposite ]]; then

    touch "$vault/coord/$role.ready"

    other=B

    [[ "$role" = B ]] && other=A

    for step in {1..30}; do

        [[ -f "$vault/coord/$other.ready" ]] && break

        sleep 0.1

    done

    [[ -f "$vault/coord/$other.ready" ]] || { echo 'barrier timeout'; exit 4; }

fi

The barrier is a teaching instrument. Each worker says it is ready, then waits for the other to say so.

It makes sure both workers hold their first lock before either asks for its second.

In ordered mode it is skipped: one worker cannot take Alpha while the other holds it.
