Step 1: the second lock, part 3

vault/worker.sh (3 of 3)

exec 9>"$vault/$second.lock"

printf '%s requests %s\n' "$role" "$second"

flock -x -w 2 9 || { echo "$role second lock timeout"; exit 5; }

printf '%s holds both\n' "$role"

After the barrier, each worker asks for its second lock, on descriptor 9, and reports what it holds.

SYNTAX

Why exec 8> and exec 9>?

exec with only a redirection opens the file for the rest of the script, so the lock lasts until the script ends.
