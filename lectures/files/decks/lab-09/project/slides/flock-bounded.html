$     flock -x -w 2 8 || exit 3

$     printf 'holding Alpha\n'

$ ) 8>vault/alpha.lock

A data file holds the data. A lock file stands for cooperative exclusive access. Creating a file named locked is not a lock.

flock -x -w 2 waits at most two seconds for the lock. If it does not get it, the status is not zero, and the script can stop waiting.

Descriptor 8 stays open until the group of commands ends, and that is when the lock is released.
