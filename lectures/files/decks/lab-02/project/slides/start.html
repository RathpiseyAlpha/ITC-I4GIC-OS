Setup: start the lab

student@server: ~

$ export OSLAB_WORKSPACE="${OSLAB_WORKSPACE:-$HOME/oslab-work}"

$ oslab start lab2

$ cd "$OSLAB_WORKSPACE/lab2"

$ mkdir -p evidence

$ oslab values lab2

  • The first line names your workspace: ~/oslab-work, unless it is already set.
  • oslab start lab2 makes the lab folder with your two reports.
  • cd takes you into it.
  • oslab values lab2 prints your own names. The next slide shows what to do with them.
