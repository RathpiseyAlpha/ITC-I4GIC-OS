Everything is a file

  • Files store data: text, pictures, programs.
  • A directory is a special file that holds other files. Windows and macOS call it a folder. The two words mean the same thing.
  • Directories inside directories make a tree.
  • Many Linux servers have no desktop, so you manage files from the command line.

FOR THE WHOLE COURSE

Why learn it here?

Every later lab works in folders on the server. If you can say where a file is, you can reach it from anywhere.
