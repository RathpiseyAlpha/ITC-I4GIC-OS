Key takeaways

01

One tree from /

Every file is somewhere below the root. Your home is /home/your-account, or ~.

02

Absolute or relative

Absolute starts at /. Relative starts where you are, so check with pwd.

03

Dots

. is here. Each .. is one level up from here.

04

Copy, move, prove

cp keeps the original, mv does not. cmp proves two files are identical.
