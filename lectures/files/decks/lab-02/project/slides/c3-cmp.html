only if a copy is wrong

$ cmp -- a.txt b.txt

a.txt b.txt differ: byte 1, line 1

You should see nothing

cmp prints nothing when two files are identical. Silence means success.

If cmp says differ

That copy is not the same. Copy it again from reports/ (Core 2, step 3) and compare again.

A name in ls does not prove the contents are the same. cmp compares the bytes.
