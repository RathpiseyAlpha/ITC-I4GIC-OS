Names with spaces

student@server: ~

$ cat my notes.txt

cat: my: No such file or directory

cat: notes.txt: No such file or directory

$ cat 'my notes.txt'

hello

The shell splits a command into words at every space. Without quotes, cat receives two names.

With quotes, the name is one word again.

Double quotes still replace a variable: "$file1" is your file name. Single quotes keep the text exactly as typed.

In this lab you also see -- before file names, as in cp -- "$file1" reports/. It means: no more options after this point.
