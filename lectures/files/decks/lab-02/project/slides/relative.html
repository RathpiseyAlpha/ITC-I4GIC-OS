Relative paths start where you are

student@server: ~

student@server:~$ cd Documents

student@server:~/Documents$ pwd

/home/student/Documents

 

student@server:/etc$ cd Documents

bash: cd: Documents: No such file or directory

A relative path does not start with /.

It starts from the folder you are in now, which pwd shows. From your home, Documents is there. From /etc, it is not.
