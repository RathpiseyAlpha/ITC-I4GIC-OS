What each folder is for (3 of 3)

In /What it is for
/snapSoftware installed as snap packages (Ubuntu)
/srvData that this server offers, for example a website
/sysNot on the disk: the kernel shows devices and its settings here
/tmpTemporary files. Every user may write here. Emptied at restart
/usrInstalled software: programs in /usr/bin, libraries in /usr/lib, documents in /usr/share
/varData that changes: logs in /var/log, mail, caches
swap.imgA file, not a folder: disk space used as extra memory (swap)
