4. Why the quotes matter

student@server: ~/oslab-work/lab2

$ ls -l "incoming/$file1"

$ ls -l incoming/$file1

The second command fails. Read its error: which names did ls receive?

Without the double quotes, the shell splits the name at its space, so ls looks for two files that do not exist.
