Your values, kept in variables

1. The command prints your values

example: your values will be different

$ oslab values lab2

Your personal values for lab2 (your-account):

  file1    = budget 2026.txt

  file2    = audit notes.txt

  owner    = Finance

  reader   = HR

  third    = Support

2. Type them into shell variables

type your own values

$ file1='budget 2026.txt'

$ file2='audit notes.txt'

$ owner=Finance

$ reader=HR

$ third=Support

Keep the quotes: your file names have a space. In a new terminal, run cd and set them again.
