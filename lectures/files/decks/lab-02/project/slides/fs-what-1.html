What each folder is for (1 of 3)

In /What it is for
/binLink to /usr/bin: the programs everybody uses, such as ls, cp and mv
/bootThe kernel and the files that start the system
/cdromWhere an installation disc appears. Left over from installing Ubuntu
/devDevices shown as files: disks, terminals, /dev/null
/etcSettings of the system (configuration files), for example /etc/passwd
/homeOne home folder for each user
/lib, /lib64Links to /usr/lib and /usr/lib64: libraries that programs need
/lost+foundPieces of files rescued by a disk check. Only root can open it
