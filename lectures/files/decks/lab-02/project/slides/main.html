The folders you meet in this course

FolderWhat it holds
/The root: everything is below it
/binPrograms everybody can run: ls, cp, mv and the others
/etcSettings of the system (configuration files)
/homeOne home folder for each user
/tmpTemporary files, deleted at restart
/usrInstalled software
/mediaDisks and USB sticks

ls / shows the real list. It is longer; these are the ones you need now.
