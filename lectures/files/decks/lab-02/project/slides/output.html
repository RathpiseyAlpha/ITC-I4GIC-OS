Sending output somewhere else

You typeWhat happens
ls > list.txtSaves the output in the file, replacing what was there (Lab 1)
ls >> list.txtAdds the output to the end of the file (Lab 1)
ls | sortThe pipe passes the output to the next command; sort puts the lines in order
ls | tee list.txttee shows the output on the screen and also saves it in the file

student@server: ~

$ find demo -type f | sort | tee files.txt

demo/School/Art/poster.txt

demo/School/Math/copy.txt

Read it from left to right: find lists the files, sort puts them in order, tee shows the list and saves it. You use exactly this in Core 3.
