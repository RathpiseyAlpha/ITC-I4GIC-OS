What each folder is for (2 of 3)

In /What it is for
/mediaUSB sticks and DVDs appear here when they are plugged in
/mntA place where the administrator attaches a disk for a while
/optOptional software installed outside the package manager
/procNot on the disk: the kernel shows running processes here, for example /proc/cpuinfo
/rootThe home of the administrator account, root. It is not the root /
/runInformation about the system since it started. Kept in memory
/sbinLink to /usr/sbin: programs for the administrator
