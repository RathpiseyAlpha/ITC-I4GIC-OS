A signal handler that does almost nothing

signal_demo.c

static volatile sig_atomic_t stop;

static void on_term(int sig) {

    (void)sig;

    stop = 1;  /* only set a flag */

}

/* in main: register it, then loop */

struct sigaction sa = {0};

sa.sa_handler = on_term;

sigaction(SIGTERM, &sa, NULL);

while (!stop) { /* work */ }

/* print and clean up here, after the loop */

The handler only sets a flag. Printing and cleanup happen in the normal loop, not inside the handler.

Keep a ten-second limit. Start it, note its own PID, and send kill -TERM to that PID only.

A join waits for completion. A mutex protects shared data. A signal flag is neither.
