FunctionWhat it doesError reporting
pthread_createStarts a new thread that runs a functionReturns an error number, 0 on success
pthread_joinWaits until one particular thread has finishedReturns an error number, 0 on success
strerror(rc)Turns an error number into textUse it instead of errno here

These functions return the error number directly. They do not set errno. Check every return value. Compile with -pthread.
