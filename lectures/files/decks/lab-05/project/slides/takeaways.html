Key takeaways

01

Thread or process

Threads share memory in one process. Forked processes get separate copies.

02

Create, then join

Check every return code, and join each thread you created.

03

Completion is not protection

A join says it finished. A mutex says who may write now.

04

Bound every run

timeout 5 keeps a mistake from running forever. Exit 124 means it ran out of time.
