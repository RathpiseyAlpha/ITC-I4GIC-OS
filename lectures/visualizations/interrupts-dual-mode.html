Interrupts and Dual-Mode Operation

Week 1 — follow the CPU as a device interrupt, a system call, the timer and an illegal instruction each force a switch from user mode to kernel mode and back
🎯 Learning objectives — what you should be able to do (click to minimize)
  • Describe the steps the CPU and the OS take when an interrupt arrives.
  • Explain the mode bit and name the events that switch the CPU into kernel mode.
  • Tell apart a hardware interrupt, a trap (system call) and an exception.
  • Decide whether an instruction is privileged, and say what happens if a user program tries to run it.
