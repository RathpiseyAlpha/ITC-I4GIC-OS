Threading Models — user threads and kernel threads

Week 4 — map user threads onto kernel threads many-to-one, one-to-one or many-to-many, then block one of them and see who else stops
🎯 Learning objectives — what you should be able to do (click to minimize)
  • Tell a user thread from a kernel thread, and say which one the OS scheduler can see.
  • Describe the many-to-one, one-to-one and many-to-many models.
  • Predict what happens to the other threads when one thread makes a blocking system call in each model.
  • Explain which models can use several cores at the same time, and what each one costs.
