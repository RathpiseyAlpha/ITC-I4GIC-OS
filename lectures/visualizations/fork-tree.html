🎯 Learning objectives — what you should be able to do (click to minimize)
  • Explain what fork() returns in the parent and in the child, and where each one continues.
  • Draw the process tree for a program with several fork() calls and count the processes.
  • Predict how many times a printf after the forks runs.
  • Explain why the order of the output lines can change from run to run.
