UNIX File Permissions

Week 12 — toggle the rwx bits, type chmod commands, and test who is allowed to do what to a file or a directory
🎯 Learning objectives — what you should be able to do (click to minimize)
  • Read a permission string such as -rwxr-x--- and convert it to octal and back.
  • Write a chmod command in octal and in symbolic form to reach a given permission.
  • Decide whether an access is allowed, using the rule that only one class (owner, group or other) is checked.
  • Explain what r, w and x mean for a directory, and how umask sets the permissions of new files.
