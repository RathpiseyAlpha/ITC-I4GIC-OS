Threads in Motion — one process, many kernel threads

Week 4 — watch one program create threads, see the kernel give each one an ID and a core, and read the same facts from ps -L. It loops by itself, or you can click through it step by step.
🎯 Learning objectives — what you should be able to do (click to minimize)
  • Say that every pthread is backed by a kernel thread with its own thread ID, and that the main thread's ID equals the PID.
  • Read the LWP, NLWP and PSR columns of ps -L and match them to what the kernel is doing.
  • Follow a thread through ready, running, sleeping and finished, and a context switch between two threads.
  • Name the kernel's own threads, such as kthreadd, and say that they also need the CPU.
