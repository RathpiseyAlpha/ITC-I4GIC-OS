# Lab 3 optional extensions

Complete these only after the [120-minute core](lab3-instruction.md). Work independently on owned files and record a prediction, a normal and an edge test, and a short explanation. These tasks do not alter the required rubric.

1. Use a wildcard to select only `.txt` files, then show a counterexample for an overbroad pattern.
2. Build a user-local shared object in a VM or account with `gcc`, load it with a private path, and compare with a missing-library failure. GRUB work is separately VM-only after snapshot and recovery preparation.
